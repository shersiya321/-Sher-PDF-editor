# Online APK Build

1. Create a GitHub repository.
2. Upload all files/folders from this project to the repository root.
3. Open **Actions** → **Build APK** → **Run workflow**.
4. Wait for the build to finish.
5. Open the completed workflow run and download **PDFEditor-debug-apk** from Artifacts.
6. Extract the downloaded ZIP and install the APK on your Android phone.

The workflow builds a debug APK and does not require Android Studio on your computer.
